The four-act movie

Every act fixes the last act’s failure.

Do not start with the final architecture. Earn each dependency by finding the problem it solves.

ACT I

The Naked Counter

A Map, timestamps, and arithmetic. Correct for one process and the best way to learn the algorithms.

Plot twist: a second pod silently doubles every limit.
ACT II

One Shared Brain

Redis gives every pod one counter. Lua makes read → decide → write one atomic step.

Plot twist: Redis restarts and the month's billable truth disappears.
ACT III

Speed and Truth

Redis protects each second. Postgres holds plans and a durable usage ledger. Hot path and truth stop fighting.

Plot twist: a health check and a million-node GraphQL query both count as “one.”
ACT IV

Past Requests/Second

Cost, concurrency, adaptive limits, priority, and load shedding model the work the service actually performs.

This is where the large APIs live. You still start in Act I.
